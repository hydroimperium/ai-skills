These prompts are for tools where you cannot install a skill, or when you want to paste a prompt into a chat. The full versions live in [`../skills/`](../skills/).

| Category | Prompt | Use |
|---|---|---|
| Meta | [prompt-enhancer](meta/prompt-enhancer.md) | Turn a rough request into a detailed prompt |
| Meta | [grill-me](meta/grill-me.md) | Stress-test a plan with a structured interview |
| Meta | [plan](meta/plan.md) | Write a spec, plan, or task breakdown |
| Engineering | [debug](engineering/debug.md) | Find a root cause before fixing |
| Study | [learn](study/learn.md) | Learn a topic with active recall |
| Study | [russian-academic](study/russian-academic.md) | Russian lab reports, coursework, and VKR |
| Writing | [professional-writing](writing/professional-writing.md) | Write clear emails and documents |
| Writing | [humanizer](writing/humanizer.md) | Remove AI-slop from text |
| Language | [russian-editor](language/russian-editor.md) | Edit Russian prose |
| Work | [meeting](work/meeting.md) | Prepare or summarize a meeting |
