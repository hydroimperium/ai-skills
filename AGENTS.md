# AGENTS.md

Правила для ИИ-агентов, которые работают с этим репозиторием.

## Что это за репозиторий

Это коллекция Agent Skills, слэш-команд и standalone-промптов. Основной контент — Markdown. Главный навык — `skills/meta/prompt-enhancer`.

## Перед изменениями

1. Прочитайте `README.md`, `docs/SKILL-FORMAT.md` и `docs/SOURCES.md`.
2. Проверьте, нет ли уже похожего навыка в `skills/<category>/`.
3. Для нового навыка используйте `npm run new -- <name> --category <category>`.
4. Не перезаписывайте чужие изменения и не удаляйте навыки без явной просьбы.

## Категории

`meta`, `engineering`, `study`, `writing`, `language`, `work`, `data`, `product`, `design`.

## Обязательные правила для навыков

- Каждый навык — папка `skills/<category>/<name>/` с файлом `SKILL.md`.
- `name` в frontmatter: lowercase, цифры и дефисы, совпадает с именем папки.
- `metadata.category` совпадает с папкой категории.
- `description`: что делает навык и когда его использовать; до 1024 символов.
- Тело `SKILL.md` — до 500 строк. Длинные детали выносите в `references/`.
- Инструкции пишите на английском, императивно и конкретно.
- Не добавляйте секреты, токены, персональные данные и опасный код.
- Не копируйте текст из источников без совместимой лицензии и атрибуции.
- Если идея взята из другого проекта, укажите источник в `metadata.inspired-by` и в `docs/SOURCES.md`.

## Обязательные правила для команд

- Команда — файл `commands/<name>.md`.
- Имя файла становится именем команды: `plan.md` → `/plan`.
- В frontmatter только `description`; тело — шаблон промпта.
- Используйте `$ARGUMENTS` для аргументов.
- Команда должна загружать существующий навык строкой вида ``Load the `skill-name` skill``.
- Не добавляйте `template` в frontmatter Markdown-команды.

## Проверка

Перед завершением работы запустите:

```bash
npm run validate
```

Проверяются и навыки, и команды.

Если меняли промпт-энхансер, проверьте, что `prompts/meta/prompt-enhancer.md` и `skills/meta/prompt-enhancer/SKILL.md` не противоречат друг другу.

## Стиль

- README и документация — по-русски.
- Содержимое навыков — по-английски, чтобы модели стабильнее следовали инструкциям.
- Без эмодзи, канцелярита и длинных вступлений.
- Не обещайте, что тесты или сборка прошли, без свежего вывода команд.
